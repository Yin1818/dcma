# DCMA 平台交付说明

## 运行条件

- Windows 电脑安装 Node.js 18 或更高版本（建议使用 Node.js LTS）。
- 运行电脑能通过网络连接到 MySQL 服务。
- MySQL 中已有 `dcma` 数据库及平台需要的数据表（`real_data`、`real_data_01` 至 `real_data_04`）。本包不含数据库和业务数据。

## 首次配置

1. 将 `.env.example` 复制一份并命名为 `.env`。
2. 编辑 `.env`，填写接收方可以访问的 MySQL 地址、端口、用户名和密码。不要把真实密码发到群聊或放进公开网盘。
3. 双击 `启动平台.bat`。也可以在此文件夹打开终端，运行 `node server.js`。
4. 浏览器访问 `http://localhost:3000/`。

平台的故障处理方案会写回 MySQL。数据库账号需要有相应表的读取、更新权限；首次使用故障分析时还可能需要 `ALTER` 权限以添加 `actual_solution` 列。建议由数据库管理员创建专用账号并按需授权，不要使用 root 账号。

`.env` 中的 `PORT` 可更改平台端口。若端口被占用，改成其他空闲端口后，浏览器地址也要相应修改。

## 发送与网络

可以直接发送整个文件夹，或发送压缩后的 ZIP。接收方解压后按以上步骤配置即可。不要发送包含数据库密码的 `.env` 文件。

当前启动脚本打开的是本机地址。若多人要从其他电脑访问，需要让运行平台的电脑和访问者处于可互通网络，并配置防火墙及服务访问方式；不要把未设访问控制的平台端口直接暴露到公网。数据库也必须允许运行平台的电脑连接。
